# Draft Connect PR

Title: Add native platform imports and prepare the macOS v0.1.3 pilot

Opening an **Import to Connect** link from the platform now brings up Connect,
redeems the single-use setup natively, fills the gateway and permitted client
choices, and fetches models. Users review selections and click Import before
configuration changes. The permanent API key stays out of app-opening URLs,
renderer handoff state and browser storage.

The app supports cold/running-instance delivery, issuer/gateway review, expired
link retry, cancellation, mixed-group choices and Claude Code-only policy. It
queues handoffs while restore review is open and preserves the gateway name
on completion. The default gateway, restore and add-gateway cards now have
consistent 10px spacing. Existing backup/restore behavior remains intact.

Validation on macOS arm64: 67 Rust tests, 12 frontend state tests, 3 asynchronous
App/RestorePanel lifecycle tests, TypeScript, frontend build, desktop Clippy,
formatting, and packaged ZIP/version/protocol/signature checks. Edge smoke
covers cold/running-app handoff, fake-key configuration import and restore;
real client config hashes remain unchanged. See `VERIFICATION.md`.

Release scope: macOS v0.1.3 candidate only, with draft GitHub notes in
`docs/releases/v0.1.3-macos.md`. The matching platform update must be deployed.
Kendrick and YC complete `docs/testing/macos-acceptance.md` separately, including
a real local client request, before Windows work begins. This PR description
does not claim publication, deployment or either person's acceptance result.
