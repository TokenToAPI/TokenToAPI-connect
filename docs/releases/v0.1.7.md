## Fixes and improvements

- Expand the fallback catalog to 24 verified model capability declarations, including GPT-5.5 and older Codex models. The two GPT-OSS models remain text-only.
- Preserve image capabilities for arbitrary model names and aliases using flat, nested provider, and native gateway metadata formats; explicit gateway limits remain authoritative.
- Read native Codex cached capabilities for newer models absent from the bundled table.
- Name models with missing or malformed capabilities in the import warnings instead of silently treating unverified text-only fallback as confirmed support.
- Audit the live production GPT manifest and add a regression for every currently exposed GPT model.

**Existing users:** install v0.1.7, fetch models again, click **Import**, then fully quit/reopen Codex and start a new chat. Updating Connect alone does not refresh a previously imported catalog.

## Verification

- 95 Rust tests, desktop Clippy, formatting, TypeScript checks, 15 frontend tests, 3 lifecycle tests, and the production builds passed.
- Seven native Codex 0.162.1 scenarios passed against an isolated fake gateway. The full matrix checks 24 model declarations and sends URL/local-file images for all 22 vision models (44 image turns), alongside repair and exact-restore coverage.
- Production discovery advertises images correctly for all four live GPT models. Actual production image-inference probes were blocked by insufficient balance, so upstream image acceptance is not claimed.
- macOS arm64 built natively and passed signature, architecture, version, protocol, and ZIP checks. Windows x64 was cross-compiled and passed PE/static-dependency/ZIP checks; native Windows execution remains unverified.
- Unknown models still require trustworthy gateway or native metadata; an explicitly text-only route is not changed into an image route. See VERIFICATION.md for the evidence and remaining limits.
