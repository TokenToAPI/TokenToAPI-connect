# TokenToAPI Connect v0.2.2

- Give Codex, Claude, Gemini and Grok distinct provider icons throughout setup.
- Add Gemini CLI setup using the gateway's native Gemini API and the model list available to your key.
- Choose one default Gemini chat model. Switch later using `/model MODEL_ID` in Gemini CLI; its built-in model menu remains managed by Gemini CLI.
- Back up Gemini settings and API environment before import. Reimport preserves unrelated settings, MCP servers and OAuth files; restore returns the original files exactly.
- Enable Gemini-key Import to Connect with the companion gateway update. Older Connect versions receive a safe unsupported-client response; existing client handoffs remain compatible.
- Exclude Gemini image, speech, live/audio and embedding models, plus dedicated Imagen/Veo/Lyria models, from coding-client selections.

Gemini CLI reads user settings from `.gemini/settings.json` and API values from `.gemini/.env` beneath the user home (or `GEMINI_CLI_HOME`). Shell variables, project environment/settings, folder trust and managed policies can override or prevent these user settings from loading. Fully restart the CLI after import. Complex multiline environment files are left untouched with an actionable error.

Update packages use the existing trusted updater signing key. macOS remains ad-hoc signed/unnotarized; Windows is not publisher-signed. Verification details and limitations are recorded in VERIFICATION.md.
