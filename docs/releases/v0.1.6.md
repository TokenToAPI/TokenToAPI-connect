## Fixes and improvements

- Fix Codex rejecting image attachments for GPT-6 Astra and the verified GPT-6.x/GPT-5.6 models when the gateway returns model IDs without input capability metadata.
- Keep explicit gateway input capabilities authoritative, including intentional text-only routes; unknown models retain the conservative text-only fallback.
- Filter unsupported, malformed, and duplicate gateway modalities so audio/video metadata cannot prevent Codex from loading its chat catalog.
- Correct the native image regression harness so it actually sends URL and local-file images, checks model-specific limits, and verifies repair of stale text-only catalogs on reimport.

**Existing users:** install v0.1.6, fetch models again, click **Import**, then fully quit and reopen Codex and start a new chat. Updating Connect alone does not refresh a previously imported catalog.
