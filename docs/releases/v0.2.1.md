## Fixes and improvements

- Preserve existing Claude Code MCP Tool Search settings when importing or switching gateways.
- Add an explicit setting to preserve, enable, or disable MCP Tool Search for Claude Code Terminal and VS Code.
- Avoid claiming automatic gateway capability detection. The gateway must forward `tool_reference` blocks, and the selected Claude Code version and ToolSearch permissions must support the feature.
- Keep Claude Desktop, Codex, and Grok setup behavior unchanged.

**After updating:** refresh the model list, review the client settings, import again, then fully quit and reopen Claude Code before starting a new session. Updating Connect alone does not rewrite existing client configuration.
