## Fixes and improvements

- Check for app updates automatically on startup, or use **Check for updates**. Install with **Update and restart**, with download progress and retry handling.
- Verify update signatures and the signed release version before installation. App updates preserve gateway preferences, client configuration, and restore backups.
- Add a per-user Windows installer for ongoing updates. The portable ZIP remains available; its first in-app update installs the managed copy, so use the installed shortcut afterward.
- Add **Refresh models** to retrieve current gateway capabilities without downloading a new Connect release. Review the refreshed models and click **Import** to apply them.
- Publish a signed update manifest with each release, and provide repeatable release packaging and Windows installer smoke tests.

**Existing users:** manually install v0.1.8 once to get the updater. On macOS, move the app to a writable Applications folder before opening. On Windows, use the setup installer. Future app updates can then be installed from Connect. To repair an existing Codex image catalog, refresh models, import, then fully quit/reopen Codex.

signing. macOS still uses an ad-hoc signature and is not notarized; Windows is
