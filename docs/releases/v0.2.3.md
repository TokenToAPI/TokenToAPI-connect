## Fixes and improvements

- Fix the scrambled TokenToAPI Connect icon that could appear at small sizes in macOS. Connect now uses a macOS icon generated by Tauri.

**After updating:** Restart Connect to load the corrected icon. Your configured clients and backups carry over.

**Existing users:** Use **Check for updates → Update and restart** in v0.1.8 or newer. Earlier versions require a one-time manual download.

## Verification

- macOS decoded the corrected icon at 16×16, 32×32 and 128×128 at both 1× and 2×. The ZIP and updater archive contain identical app bundles.
- Both updater signatures passed. An isolated v0.2.2 Mac app upgraded to v0.2.3 and kept its backup. Local coverage included 107 Rust, 22 UI/helper and 11 lifecycle tests.

All 108 native Windows Rust tests and the Gemini CLI loopback compatibility check passed. [Windows acceptance run](https://github.com/TokenToAPI/TokenToAPI-connect/actions/runs/46045233089)
