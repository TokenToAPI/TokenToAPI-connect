## Fixes and improvements

- Fix the scrambled TokenToAPI Connect icon that could appear at small sizes in macOS. Connect now uses a macOS icon generated by Tauri.

**After updating:** Restart Connect to load the corrected icon. Your configured clients and backups carry over.

**Existing users:** Use **Check for updates → Update and restart** in v0.1.8 or newer. Earlier versions require a one-time manual download.

## Verification

See [verification notes](https://github.com/TokenToAPI/TokenToAPI-connect/blob/main/VERIFICATION.md) for the macOS icon regression and platform package checks.

Update packages use the existing trusted updater signing key. The macOS app is ad-hoc signed and unnotarized. The Windows installer uses updater signing and is distributed without a Windows publisher signature.

See `SHA256SUMS-0.2.3.txt` (also available as `SHA256SUMS.txt`) for package checksums.
