## Fixes and improvements

- Add setup for the official Grok CLI alongside Codex and Claude. Import selected gateway models with their declared context capacities and supported reasoning choices, and restore the original configuration when needed.
- Keep Grok chat models available in compatible clients while excluding Grok image, video, and voice generators from chat selection, including provider-prefixed names.
- Enable native Grok CLI in platform imports for Responses-compatible keys. Older Connect releases retain their compatible client lists; Claude-Code-only restrictions remain enforced.
- Expand native Grok, Codex image-input, and version-to-version updater regression coverage.

**Existing users:** use **Check for updates → Update and restart** in v0.1.8. Older versions need a manual download once. After updating, refresh models, review the selection and import, then restart the target client. Grok image input depends on the gateway's declared model capabilities; text-only or unknown models are not automatically marked as vision-capable.
